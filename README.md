# Data Cleaning & Reporting Automation

## Overview
This project automates data cleaning and reporting using Python.

## Features
- Removed missing values
- Removed duplicate records
- Generated automated summary report
- Created sales and profit visualizations

## Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Files
- Data_Cleaning_Reporting_Automation.ipynb
- Sample - Superstore.csv
- Data_Report.csv
- sales_by_category.png
- profit_by_category.png

## Outcome
This project demonstrates automated data preprocessing and reporting for business datasets.
